Koneksi Cloud Firestore

Pengaturan Konfigurasi Firebase

Hubungkan website ke project Firebase Anda untuk menyimpan data pelanggan, kode referral, katalog fitur, pricing, dan konten landing page secara real-time.

Status: Mode Sesi Lokal

Referensi Firestore Security Rules

Gunakan aturan berikut pada Firebase Console Anda untuk koleksi features, pricing, siteSettings, customers, dan referrals.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{collectionName}/{docId} {
      allow read: if collectionName in ['features', 'pricing', 'siteSettings', 'customers', 'referrals'];
      allow write: if request.auth != null;
    }
  }
}
